# Aujuda — versão web

Site estático pronto para GitHub Pages.

## Arquivos necessários
- `index.html`
- `style.css`
- `script.js`

Coloque os três arquivos na raiz do repositório.

## Publicar no GitHub Pages
1. Envie os 3 arquivos para a raiz do repositório.
2. No GitHub, abra **Settings → Pages**.
3. Em **Build and deployment**, escolha **Deploy from a branch**.
4. Selecione a branch `main` e a pasta `/ (root)`.
5. Salve.

## Observação
Esta versão é uma demonstração front-end. Cadastro de animais e usuário usa `localStorage`, então os dados ficam apenas no navegador atual. Para uso real, o próximo passo é integrar backend, banco de dados, autenticação real e armazenamento de imagens.
