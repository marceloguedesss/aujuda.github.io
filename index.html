Sobre o projeto

Um projeto acadêmico que pode ir além do terminal.

O Aujuda nasceu como um programa desenvolvido em C para cadastrar e buscar animais perdidos. Esta versão web mantém a mesma ideia central, mas apresenta a proposta de forma mais visual, acessível e pronta para um portfólio.

01

Propósito social Uma solução simples para uma situação real.

02

Evolução técnica Do terminal para uma experiência web interativa.

03

Pronto para expandir Base preparada para receber backend e banco de dados no futuro.
