TECNOLOGIA COM PROPÓSITO

Uma ideia simples.
Uma ajuda de verdade.

O Aujuda nasceu como um programa de terminal desenvolvido integralmente em C por Marcelo Guedes, com o objetivo de cadastrar e buscar animais perdidos.

Esta versão apresenta a ideia em uma interface web, com a lógica de cadastro e busca adaptada para JavaScript. Ela não executa o programa C original.

É uma demonstração para portfólio: não tem contas reais, banco de dados compartilhado nem publicação de anúncios. Uma futura versão poderá conectar pessoas e informações de animais de verdade.
